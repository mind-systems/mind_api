## Phase 18 — Fix: flush buffers on session-revoke

Currently if `ModuleStateGrpcController.handleSessionRevoked` catches an error from `stopActivity`, no `SessionEvents.INTERRUPTED` is emitted → engines don't flush → `closeAll` terminates streams → in-memory buffers wait for the next periodic flush or die with the process. Phase 19 doubles the loss surface (biometric buffers). Fix is a new `SessionEvents.REVOKED` event emitted unconditionally from the revoke handler; both engines flush on it. Full spec: `.ai-factory/notes/04-session-revoke-flush-fix.md`.

- [x] **Add `SessionEvents.REVOKED` to enum** — Append `REVOKED: 'session.revoked'` to `src/realtime/events/session.events.ts`. Standalone — no consumer yet. [2m 42s]

- [x] **Emit `REVOKED` from `handleSessionRevoked` — only on `stopActivity` failure** — Per note 04 §"Emit-only-in-catch". Inject `EventEmitter2` into `ModuleStateGrpcController`. Resolve `sessionId = activityEngine.getActiveSession(userId)?.sessionId` **before** `stopActivity` (which may clear in-memory state). Run `try { await stopActivity }`; **inside the catch** (and only there) — if `sessionId` was non-null, emit `SessionEvents.REVOKED, { sessionId }`. Then `closeAll(userId)`. Reason emit is catch-only: on happy path `ActivityEngine.stopActivity` already emits `SessionEvents.INTERRUPTED` at the last line; a second unconditional `REVOKED` emit would race with the in-flight `flush` (handler-A slices `buffer.samples`, `await save` in flight, handler-B slices the same non-empty array → two inserts of identical sample batches into `session_stream_samples` and after Phase 19 into `bio_session_samples`). Catch-only means only failure paths — where `INTERRUPTED` was never reached — emit `REVOKED`. [11m 49s]

- [x] **`StreamEngine.onSessionRevoked` handler** — Add `@OnEvent(SessionEvents.REVOKED) async onSessionRevoked(payload: { sessionId: string })` to `src/realtime/services/stream-engine.service.ts` — copy/paste body of `onSessionInterrupted` (flush + delete buffer), only change the log message. [3m 45s]
