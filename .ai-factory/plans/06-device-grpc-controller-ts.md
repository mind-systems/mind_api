# Plan: device.grpc.controller.ts

## Context
Add a gRPC controller for the Device service, implementing the `DeviceServiceController` interface generated by ts-proto and delegating to the existing `DeviceService`. The device `Ping` RPC is unauthenticated (same as the HTTP endpoint), so no JWT/session handling is required.
