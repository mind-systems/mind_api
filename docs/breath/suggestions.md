# Рекомендации (Suggestions)

Эндпоинт рекомендаций подбирает дыхательные сессии, подходящие пользователю по времени суток и уровню сложности. Результат — случайная выборка из собственных сессий пользователя и расшаренных сессий других пользователей (`shared = true`) с интеллектуальной фильтрацией.

---

## Эндпоинт

### `GET /breath_sessions/suggestions`

**Авторизация:** Bearer JWT обязателен.

**Query-параметры:**

| Параметр | Тип | Обязателен | Описание |
|----------|-----|------------|----------|
| `timeOfDay` | enum | да | Время суток: `morning`, `midday`, `evening` |

**Ответ — 200 OK:**

```json
[
  {
    "id": "uuid",
    "description": "Утренняя практика",
    "exercises": [...],
    "complexity": 24000,
    "timeOfDay": "morning",
    ...
  }
]
```

Возвращает массив до **4 сессий** в случайном порядке. Если подходящих сессий нет — пустой массив.

---

## Поле `timeOfDay` на сессиях

Каждая сессия дыхания может быть помечена временем суток:

| Значение | Описание |
|----------|----------|
| `morning` | Утренняя практика |
| `midday` | Дневная практика |
| `evening` | Вечерняя практика |
| `null` | Не задано (по умолчанию) |

Поле опционально — задаётся при создании (`POST`) или обновлении (`PATCH`, `PUT`) сессии. Сессии без `timeOfDay` не попадают в рекомендации.

---

## Алгоритм фильтрации

Рекомендации строятся по трём критериям:

1. **Пул сессий** — собственные сессии пользователя + все расшаренные сессии других пользователей (`shared = true`)
2. **Время суток** — `timeOfDay` совпадает с запрошенным
3. **Сложность** — если у пользователя есть история, применяется верхний порог

### Фильтр по сложности

Используется поле `maxCompletedComplexity` из статистики пользователя (см. [Статистика](../stats/stats.md)):

```
baseline = max(maxCompletedComplexity, SUGGESTIONS_BEGINNER_BASELINE)
complexity ≤ baseline + SUGGESTIONS_COMPLEXITY_THRESHOLD
```

Для новичка (`maxCompletedComplexity = 0`) baseline берётся из `SUGGESTIONS_BEGINNER_BASELINE` (по умолчанию 40), что даёт потолок 40 + 50 = 90. По мере роста уровня пользователя `maxCompletedComplexity` вытесняет baseline, и потолок растёт вместе с ним.

### Случайный порядок

Из отфильтрованного набора выбирается до 4 сессий через `ORDER BY RANDOM() LIMIT 4`. Это обеспечивает разнообразие — при одинаковых входных данных пользователь получает разные рекомендации.

---

## Конфигурация

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `SUGGESTIONS_COMPLEXITY_THRESHOLD` | `50` | Допустимое превышение сложности над baseline. Чем выше значение, тем более сложные сессии попадают в рекомендации. |
| `SUGGESTIONS_BEGINNER_BASELINE` | `40` | Стартовый уровень для пользователей без истории. Итоговый потолок для новичка: baseline + threshold. |
