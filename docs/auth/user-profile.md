# User Profile

После аутентификации пользователь может обновить данные профиля через `rpc UpdateProfile` сервиса `UserService`. Идентификатор пользователя извлекается из metadata gRPC-вызова.

## Обновление профиля

```
rpc UpdateProfile(UpdateProfileRequest) returns (UserDto)

UpdateProfileRequest:
  name     — опционально; отображаемое имя
  language — опционально; предпочтительный язык ("en", "ru")
```

`UpdateProfileRequest` принимает одно или оба поля — можно передать только то, что нужно изменить. Допустимые значения `language` ограничены поддерживаемыми локалями; любое другое значение вернёт `INVALID_ARGUMENT`. При успешном сохранении возвращается `UserDto` с актуальными данными профиля.

## Язык интерфейса

Поле `language` хранится в таблице `users` и используется для локализации системных писем: при следующей отправке кода сервер возьмёт язык из профиля, если клиент не передаст `locale` явно в `SendCodeRequest`. Список поддерживаемых локалей и логика нормализации описаны в разделе [Email Auth → Письмо](email-auth.md#письмо).
