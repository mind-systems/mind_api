# Статистика пользователя

`StatsModule` агрегирует долгосрочную статистику сессий по каждому пользователю. Статистика обновляется автоматически после завершения или abandonment каждой квалифицирующей сессии.

---

## gRPC-метод

```
rpc GetStats(GetStatsRequest) returns (GetStatsResponse)   — StatsService
```

`GetStatsRequest` пустое — пользователь определяется по metadata gRPC-вызова. Возвращает агрегированную статистику аутентифицированного пользователя.

**Поля `GetStatsResponse`:**

| Поле | Тип | Описание |
|------|-----|----------|
| `total_sessions` | int32 | Количество завершённых квалифицирующих сессий |
| `total_duration_seconds` | int32 | Суммарная длительность всех квалифицирующих сессий (секунды) |
| `current_streak` | int32 | Текущая серия — количество последовательных дней с хотя бы одной квалифицирующей сессией |
| `longest_streak` | int32 | Рекорд серии за всё время |
| `last_session_date` | string (YYYY-MM-DD), optional | UTC-дата последней квалифицирующей сессии |
| `max_completed_complexity` | double | Сглаженная максимальная сложность завершённых сессий дыхания |

Если у пользователя ещё нет записей, все числовые поля возвращают `0`, `last_session_date` отсутствует.

---

## Сглаженная сложность (`maxCompletedComplexity`)

Поле отслеживает прогресс пользователя по сложности дыхательных практик. Обновляется при каждой квалифицирующей сессии по формуле экспоненциального сглаживания:

```
maxCompletedComplexity += (sessionComplexity − maxCompletedComplexity) × 0.3
```

- Если новая сессия сложнее — значение **плавно растёт** (не скачком)
- Если новая сессия проще — значение **медленно снижается**
- Коэффициент `0.3` балансирует между отзывчивостью и устойчивостью к выбросам

Значение используется эндпоинтом рекомендаций для [фильтрации по сложности](../breath/suggestions.md).

## Квалифицирующие сессии

Сессия засчитывается в статистику только при достижении минимального порога длительности:

```
durationSeconds = (endedAt - startedAt) / 1000
засчитывается = durationSeconds >= WS_MIN_SESSION_DURATION_S  (по умолчанию: 10)
```

Сессии короче порога игнорируются — они не влияют ни на счётчики, ни на серию.

Обрабатываются три события: `session.completed`, `session.abandoned` и `session.interrupted`. Брошенная или прерванная сессия засчитывается, если её длительность превышает порог.

---

## Правила серии

Серия рассчитывается по **UTC-датам** (`lastSessionDate` хранится в формате `YYYY-MM-DD`).

| Ситуация | Результат |
|----------|-----------|
| Предыдущей сессии нет (`lastSessionDate` равен null) | `currentStreak = 1` |
| Дата сессии совпадает с `lastSessionDate` (тот же день) | `currentStreak` не меняется |
| Дата сессии = `lastSessionDate + 1 день` | `currentStreak += 1` |
| Дата сессии > `lastSessionDate + 1 день` | `currentStreak = 1` (серия прервана) |

После обновления `currentStreak`:

```
longestStreak = max(currentStreak, longestStreak)
```

## Конфигурация

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `WS_MIN_SESSION_DURATION_S` | `10` | Минимальная длительность сессии (секунды) для учёта в статистике |

## Внутренняя архитектура

```
ActivityEngine / ActivitySessionStore
        ↓  emits
  session.completed / session.abandoned / session.interrupted  (EventEmitter2)
        ↓  @OnEvent
     StatsWorker
        ↓  вызывает
     StatsService.finalise()
        ↓  upsert
     user_stats (PostgreSQL)
```

`StatsService` выполняет upsert внутри транзакции с пессимистической блокировкой (`pessimistic_write`), что предотвращает гонку при одновременных событиях от нескольких устройств одного пользователя.
